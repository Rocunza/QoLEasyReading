# QoL: Easy Reading — 한국어 안내

제작: **ZCN** · 지원: **RimWorld 1.6 / 1.7** · [Steam 창작마당](https://steamcommunity.com/sharedfiles/filedetails/?id=3828178548)

교과서 기술 아이콘, Ctrl/Alt 반복 독서, Work 시간표 중 수동 독서 예외 처리를 제공하는 편의성 모드입니다.

## 주요 기능

- **책장 내용물 / 책 우클릭 독서 메뉴 / 거래창**에 책의 기술 아이콘(1개 또는 2개) 표시
- **Ctrl + 좌클릭**: 설정된 횟수만큼 반복 독서 예약
- **Alt + 좌클릭**: 횟수 입력창에서 반복 예약 횟수 선택
- 일반 Read 및 **Shift** 예약은 바닐라 방식 유지
- **Work 시간표에서도 직접 명령한 독서 지속**(기본 ON, 설정에서 OFF 가능). 자동 독서·기타 중단 사유는 바닐라 유지
- 한국어·영어 설정 및 기능별 ON/OFF 지원

**필수:** Harmony · **Biotech 불필요**

## 설치

[Steam 창작마당](https://steamcommunity.com/sharedfiles/filedetails/?id=3828178548)에서 구독하거나 [`Mod/QoLEasyReading`](Mod/QoLEasyReading) 폴더를 게임의 `Mods/QoLEasyReading`으로 복사하세요. 모드 목록에 Harmony와 Easy Reading을 활성화합니다. 기존 통합 모드 `ReadAndLearnQoL`과는 동시에 활성화하지 마세요.
